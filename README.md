# Productivity App

A comprehensive study and personal development platform built with React, combining note-taking, crypto tracking, and AI-powered features to enhance your learning journey.

## 🚀 Features

### Smart Note-Taking
- Intelligent organization system for study materials
- Rich text editing with markdown support
- Tags and categories for easy retrieval
- Cloud synchronization for access anywhere

### Crypto Portfolio Tracker
- Real-time cryptocurrency price tracking
- Portfolio performance analytics
- Historical data visualization
- Custom alerts and notifications

### Progress Monitoring
- Visual progress tracking for different subjects
- Milestone achievement system
- Detailed analytics and insights
- Custom goal setting and tracking

### AI Study Assistant
- Intelligent chatbot for homework help
- Study material recommendations
- Smart content summarization
- Practice question generation

### Financial Progress Tracker
- Budget planning and monitoring
- Expense categorization
- Savings goals tracking
- Financial health insights

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Styling:** Tailwind CSS
- **Backend:** Appwrite
- **Other Tools:**
  - State Management: React Context/Redux
  - Authentication: Appwrite Auth
  - Database: Appwrite Database
  - Storage: Appwrite Storage

## 🏗️ Installation

1. Clone the repository:
```bash
git clone https://github.com/Risabkshetri/finance.git
cd finance
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the root directory and add your Appwrite credentials:
```env
VITE_APPWRITE_ENDPOINT=your_endpoint
VITE_APPWRITE_PROJECT_ID=your_project_id
```

4. Start the development server:
```bash
npm start
```

## 🔧 Configuration

### Appwrite Setup

1. Create a new project in Appwrite Console
2. Set up the following collections:
   - Notes
   - CryptoPortfolio
   - ProgressTracking
   - FinancialGoals

### Environment Variables

| Variable | Description |
|----------|-------------|
| VITE_APPWRITE_ENDPOINT | Your Appwrite endpoint URL |
| VITE_APPWRITE_PROJECT_ID | Your Appwrite project ID |
